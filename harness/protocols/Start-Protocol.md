# Start Protocol

Use this protocol before editing.

1. Read the user's current task.
2. Identify scope and explicit non-changes.
3. Inspect relevant files.
4. If project rules may matter, read:
   - `harness/harness-state.json`
   - `harness/project-memory.md`
   - `harness/decisions.md`
   - relevant contracts
5. Confirm whether the target is public content, backstage content, or infrastructure.
6. State the smallest intended patch.
7. Patch only that scope.
