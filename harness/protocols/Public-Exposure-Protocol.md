# Public Exposure Protocol

Before exposing material publicly, ask:

1. Is it finished, stable, written, or publishable?
2. Is it user-authored or user-approved?
3. Does it return to Recherche / Proust as mother star?
4. Does it avoid making the project look more complete than it is?
5. Is it free of raw prompts, internal planning language, and backstage operations?
6. Has any required Harness review happened?

If any answer is no, keep the material backstage.
