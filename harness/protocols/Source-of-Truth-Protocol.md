# Source of Truth Protocol

Use this protocol when duplicate files, drafts, or public/backstage copies exist.

## Current Rule

- `content/` is the public finished-artifact surface.
- `harness/` is production and state authority for drafts under review.
- Root duplicate drafts are not authoritative until reviewed, merged, or archived.

## Required Action Before Moving

1. Identify all duplicates.
2. Identify public exposure status.
3. Identify the most current reviewed source.
4. Record uncertainty instead of deleting.
5. Move or archive only with explicit approval.
