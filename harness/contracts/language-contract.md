# Language Contract

Language Training is the precision and recomposition layer of Proustian.

It is not a generic language-learning section.

The learner remains sovereign. AI must never perform the central learning act before the learner attempts it.

## Tracks

| Track | Function | Default Status |
|---|---|---|
| French Precision | French reading recognition, lexical recognition, sentence skeletons, anchors. | working / Harness-controlled |
| EN-CN Recomposition Studio | English sentence movement, Chinese recomposition, rhythm, writing training. | active draft line / not fully public |
| Comparative Literary Induction | Proust in English translation inside the English literary world; comparative literary exercises, close reading, critical judgment, and critical writing. | working textbook line / backstage by default |

## Comparative Literary Induction

Comparative Literary Induction is the third textbook line of the language layer.

It treats Proust in English translation as part of the English literary world and uses comparative literary exercises, close reading questions, and critical writing prompts to train judgment.

It may draw on Norton-style literary pedagogy:

- brief historical or literary context
- Proust text anchor
- English-literary counterpoint
- close reading questions
- comparison drills
- critical debate prompts
- short writing assignments
- AI feedback after learner attempt
- final concept / comparison card

Comparative Literary Induction is backstage / working by default until selected units become finished public artifacts.

It may supply patterns, genealogies, contrastive examples, and critical questions, but it must not outrank the learner's own attempt or the Proustian mother-star principle.

## Publication Rule

Only stable materials may appear publicly.

Draft chapters, long source passages, raw prompts, studio files, and unreviewed comparative-induction materials remain backstage.

Public language pages must not make unfinished training material look more complete than it is.

## EN-CN Canonical Rule

After a source passage is selected, do not produce a final translation unless the reader has first attempted the passage or explicitly requests a final rendering.

No chapter is valid if AI performs the central learning act before the learner attempts it.

## Human-First Chapter Loop

Each language chapter must follow a light training loop:

Core Explanation -> Input -> Try -> AI Feedback -> Repair / Retry if needed -> Card -> Reuse

The model is not explanation-first completion. The model is practice-first formation with restrained support.

For EN-CN training pages, the default loop should increase practice density without increasing administrative burden:

Core Explanation -> Input -> Recognition Drill -> Recomposition Drill -> AI Feedback -> Repair Drill -> Thinking Question -> Transfer Drill -> Teacher Note -> Movement Card

Each training chapter must include:

1. recognition
2. production or recomposition
3. repair
4. transfer
5. one thinking question

Practice must create friction inside language, not administrative burden outside language.

## Training Principles

Every chapter should provide a small, usable input:

- a sentence
- a phrase
- a short passage
- a citation anchor
- a pattern

The input must be small enough to act on.

The learner must produce something before receiving a full answer:

- mark the subject
- find the conjugated verb
- underline inserted phrases
- draft a rough Chinese rendering
- write one sentence using the phrase
- identify where the sentence completes

AI feedback should help the learner notice a small number of important differences:

- what the learner missed
- what the learner flattened
- what the learner over-explained
- what the learner identified correctly

After feedback, the learner repairs one concrete thing:

- one sentence skeleton
- one phrase
- one Chinese rhythm problem
- one false friend
- one function word
- one delayed clause

Each chapter ends with retrieval and reuse:

- next sentence
- new passage
- own sentence
- own Chinese paragraph
- own reading card

## Feedback Boundary

AI acts as a coach, not as:

- final answer provider
- final translator
- lecture machine
- replacement reader

Default AI feedback is capped at:

- maximum 3 feedback points
- one repair instruction
- one question

Allowed AI roles:

- material provider
- coach
- corrector
- example generator
- card compressor

Forbidden AI roles before learner attempt:

- final translator
- complete parser
- movement-map provider
- full interpretation provider
- answer-key provider
- chapter author replacing learner action

## Administrative Burden Rule

Do not push backstage Harness complexity into the learner-facing chapter.

The learner-facing loop must stay light:

Try -> Feedback -> Repair / Retry if needed -> Card

Harness may preserve context backstage, but the learner should not be forced to maintain:

- audit logs
- decision ledgers
- revision state boards
- long self-reports
- multi-page reflection reports
