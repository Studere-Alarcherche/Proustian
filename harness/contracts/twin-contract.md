# Twin Contract

The digital twin layer, if created, is backstage.

## Principle

File over App.

Applications are temporary interfaces. Files are durable assets.

## Relationship

- `content/` is the public finished-artifact surface.
- `harness/` is project and task context control.
- `twin/`, if approved later, is durable self-context and concept memory.

## Boundary

Do not expose twin material publicly by default.

Do not create twin files or folders unless explicitly approved.
