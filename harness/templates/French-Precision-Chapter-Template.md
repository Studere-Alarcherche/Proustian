# French Precision Chapter Template

Use this backstage template for French Precision chapters. Do not publish a chapter generated from this template until it has been reviewed.

## What You Train

Name one recognition action.

Examples:

- recognizing cognates without overtrusting them
- detecting false friends
- seeing word families
- recognizing function words
- finding subject + conjugated verb

## Core Explanation

Give a short explanation.

Do not give a full grammar lecture.

## Input

Provide:

- 3-5 short French sentences, or
- one very short passage, or
- one phrase pattern

## Try

The learner must first mark or produce something.

Examples:

- circle the subject
- underline the conjugated verb
- mark function words
- guess word family relation
- write one sentence using the phrase

## AI Feedback Prompt

Use:

```text
Do not translate the whole sentence for me.
Check my parsing attempt.

Focus on:
1. subject;
2. conjugated verb;
3. function words;
4. the one recognition mistake I should fix first.
```

## Repair / Retry if needed

The learner repairs one recognition mistake.

No forced second attempt. No artificial failure. If the first attempt is strong, proceed to Card.

## Teacher Note

Only after the attempt and feedback:

- explain the pattern
- give 2-3 clean examples
- show the recognition cue

## Card

Create one Pattern Card:

```markdown
# Pattern Card｜[Name]

## Input

Phrase / sentence / anchor

## My Try

What I marked or wrote.

## AI Feedback

Max 3 points.

## Repair

What I corrected.

## Recognition Cue

How to recognize it next time.

## Reuse

One new sentence or next reading task.
```

## Reuse Task

Apply the same recognition move to one new sentence.
