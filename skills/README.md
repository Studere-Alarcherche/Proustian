# Skills

Human-readable documentation for Proustian skill layers.

## Layers

External skills:

- documented in `EXTERNAL-SKILLS.md`
- installed outside the repository
- may not be reliable for auto-loading in every Codex session

Project skills:

- documented in `PROJECT-SKILLS.md`
- stored in `.codex/skills/`
- written as plain Markdown instructions so they remain useful even if Codex does not auto-load them

## Rule

Do not put public course pages in this directory. Public reader-facing material belongs under `content/` only when explicitly approved.
