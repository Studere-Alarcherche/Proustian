# Self-Test — Chapter 002

## A. Recognition Check

Give the controlled English reading. Do not give the tempting false friend.

1. actuellement
2. attendre
3. ignorer
4. sensible
5. éventuellement
6. librairie
7. demander
8. déception

## B. False Friend Correction

Correct the wrong English guess.

1. `actuellement` = actually
2. `attendre` = attend
3. `sensible` = sensible
4. `éventuellement` = eventually
5. `librairie` = library
6. `prévenir` = prevent

## C. Word Type Check

Identify the word type: noun, verb, adjective, adverb, or expression.

1. actuellement
2. attendre
3. librairie
4. sensible
5. assister à

## D. Sentence Check

Give a plain English control reading.

1. Actuellement, le narrateur attend.
2. Le lecteur ignore la cause.
3. Une impression sensible apparaît.
4. Une déception transforme le souvenir.

## E. English Control Check

Answer in one or two sentences.

1. What is controlled guessing?
2. Why is English resemblance useful but insufficient?

## F. Gap Diagnosis

For each failure, name the most likely gap type.

1. You read `librairie` as "library."
2. You know `attendre` in a list but read `Le lecteur attend` as "The reader attends."
3. You translate `Une déception transforme le souvenir` before checking the subject and verb.

Possible gap types:

- False Friend Gap
- Word Type Gap
- Function Gap
- Premature Interpretation
- English Control Gap

## G. Answer Notes

### A. Recognition Check

1. actuellement = currently / at present
2. attendre = to wait for
3. ignorer = not to know / be unaware of
4. sensible = sensitive / perceptible
5. éventuellement = possibly / if necessary
6. librairie = bookstore
7. demander = to ask
8. déception = disappointment

### B. False Friend Correction

1. actuellement = currently / at present, not actually
2. attendre = to wait for, not attend
3. sensible = sensitive / perceptible, not sensible
4. éventuellement = possibly / if necessary, not eventually
5. librairie = bookstore, not library
6. prévenir = to warn / notify, not prevent

### C. Word Type Check

1. actuellement = adverb
2. attendre = verb
3. librairie = noun
4. sensible = adjective
5. assister à = expression / verb expression

### D. Sentence Check

1. Currently, the narrator waits.
2. The reader does not know the cause.
3. A perceptible / sensitive impression appears.
4. A disappointment transforms the memory.

### E. English Control Check

1. Controlled guessing means noticing resemblance, suspending certainty, checking word type and sentence function, verifying with context, and only then paraphrasing.
2. English resemblance is useful because it gives a first foothold, but insufficient because similar-looking words may diverge in meaning.

### F. Gap Diagnosis

1. False Friend Gap
2. Word Type Gap and False Friend Gap
3. Premature Interpretation and English Control Gap
