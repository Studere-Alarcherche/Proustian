# Source Locator｜iBooks

## Rule

iBooks is the reading surface. This page is only the search index.

## Workflow

1. Open this locator.
2. Copy one Search Key.
3. Search in Apple Books / iBooks.
4. Confirm Start Words and End Words.
5. Read in iBooks.
6. Return to Passage Cards.
7. Update status: found → checked → read → carded.

## Status Vocabulary

- found: locator exists but has not been checked in iBooks
- checked: search key and boundary confirmed in iBooks
- read: passage has been read
- carded: passage has a usable Passage Card
