# Language Training Placement

In Obsidian, Language Training is a flat, course-level training surface.

Active location:

`content/`

Main control file:

- [[Language-Training|Language Training]]

Primary flat-file groups:

- `LTF-*` for French Reading Textbook files
- `TT-*` for Translation Training files
- `AGENT-*` for agent rules
- `CARD-*` for Anki and Pattern Card rules
- `DIAG-*` for Diagnostic Tutor files
- `OBS-*` for Obsidian operating notes
- `VOCAB-*` for vocabulary system files
- `SELFTEST-*` for self-test files

Obsidian role:

- stores learning traces
- stores cards
- stores failed-card diagnosis
- stores chapter notes
- stores translation training logs
- stores weekly language review

Do not use Obsidian as a raw source dump.

Do not over-folder.

Use files, headings, cards, logs, and wiki links.
