# Vocabulary Progression

Vocabulary should support reading grammar and Proustian preparation.

Progression:

1. Cognates
2. False friends
3. Word families
4. Function words
5. Proust lexical fields
6. Proust-oriented micro-readings

## Principles

- Use high-yield reading vocabulary before topic vocabulary.
- Teach function words early and repeatedly.
- Mark false friends clearly.
- Use Proust-oriented vocabulary without forcing fake Proustian depth into A0 lessons.
- Keep vocabulary tied to sentence reading, not isolated memorization.
- Treat vocabulary as a repeatable recognition system, not a list.
- Convert vocabulary into cards only when each card tests one retrievable point.
- Use failed cards to revise vocabulary presentation.

## Acquisition Loop

cognate recognition → false friend warning → word family → function word → Proust lexical field → sentence encounter → Anki card → failed-card diagnosis → re-encounter
