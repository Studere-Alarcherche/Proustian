# Proust Lexical Fields

Purpose: keep vocabulary oriented toward Proust without forcing literary interpretation too early.

Core fields:

## Time

- le temps
- le moment
- le jour
- le soir
- la nuit

## Memory

- la mémoire
- le souvenir
- revenir
- se souvenir

## Perception

- voir
- regarder
- entendre
- sentir
- une sensation

## Space

- la chambre
- la maison
- le lieu

## Sentence Movement

- une phrase
- apparaître
- devenir
- sembler

Use these fields as sources for controlled vocabulary and later micro-readings.
