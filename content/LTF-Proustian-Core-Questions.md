# Proustian Core Questions

Language training supports the core Proustian question chain by sharpening terms, syntax, reading pressure, and textual return.

## U1 Note

U1 does not teach signs as a closed topic. It trains the reader to move from memory cliché to polycentric, testable, returnable reading paths.

## Book I Prototype Note

The first five French Reading Textbook chapters support U1 method by training recognition, controlled inference, relation words, and structural return.

- [[LTF-Chapter-001-Cognates-and-Reading-Confidence|Chapter 001]] trains recognition before interpretation.
- [[LTF-Chapter-002-False-Friends-and-Controlled-Guessing|Chapter 002]] trains controlled inference.
- [[LTF-Chapter-003-Word-Families-and-Recognition-Patterns|Chapter 003]] trains lexical pattern recognition.
- [[LTF-Chapter-004-Function-Words-I|Chapter 004]] trains relation-word attention.
- [[LTF-Chapter-005-What-Is-a-French-Sentence|Chapter 005]] trains grammatical return to the sentence.
