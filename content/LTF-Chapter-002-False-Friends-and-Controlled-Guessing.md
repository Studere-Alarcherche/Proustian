# Chapter 002 — When English Misleads

Subtitle: False Friends and Controlled Guessing

## 1. Chapter Aim

Learn to use French-English resemblance carefully. Cognates help reading, but some familiar-looking words mislead.

## 2. Reading Problem

After Chapter 001, the reader may begin to trust visual resemblance too much. This produces fast but false interpretations.

The problem is not guessing. The problem is uncontrolled guessing.

## 3. Core Knowledge

A false friend is a word that resembles an English word but does not share its expected meaning.

A partial cognate is a word that overlaps with English in some contexts but shifts in others.

Controlled guessing means:

1. Notice resemblance.
2. Propose a possible meaning.
3. Check against sentence context.
4. Refuse the guess if it does not fit.

## 4. Vocabulary

### 4.1 Recognition Vocabulary

| French | Misleading English expectation | Controlled reading value |
| --- | --- | --- |
| actuellement | actually | currently / at present |
| attendre | attend | to wait for |
| ignorer | ignore | not to know / to be unaware of |
| sensible | sensible | sensitive / perceptible |
| éventuellement | eventually | possibly / if necessary |
| librairie | library | bookstore |

### 4.2 New Core Vocabulary

- `actuellement`: currently
- `attendre`: to wait for
- `ignorer`: not to know
- `sensible`: sensitive / perceptible
- `éventuellement`: possibly
- `librairie`: bookstore

### 4.3 Function Words

No new function words are required yet.

Watch for context words around false friends. They often reveal whether the English guess is wrong.

### 4.4 Proust Direction

The reader must learn to use resemblance without surrendering judgment. Proustian reading requires inference, but every inference must remain testable.

### 4.5 Card Targets

- false friend recognition
- correction of English expectation
- controlled guessing steps
- error-correction cards

## 5. Forms and Patterns

| Type | Example | Risk |
| --- | --- | --- |
| adverb | actuellement | Looks like "actually." |
| verb | attendre | Looks like "attend." |
| adjective | sensible | Looks like "sensible." |
| noun | librairie | Looks like "library." |

## 6. Model Sentences

These are controlled training sentences.

1. Actuellement, le lecteur attend.
2. Le narrateur ignore une sensation.
3. Une impression sensible apparaît.
4. Éventuellement, une image revient.
5. La librairie n’est pas une bibliothèque.

## 7. Reading Method

Use the false-friend check:

1. Does the word look familiar?
2. Is it a known false friend?
3. Does the English guess fit the sentence?
4. What safer reading value should replace it?

## 8. Proustian Alignment

This chapter supports U1’s claim/problem method. A first claim about a word may be wrong. The reader must test it, expose its limit, and return to the sentence.
