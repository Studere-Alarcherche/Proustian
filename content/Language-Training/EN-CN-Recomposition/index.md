# EN-CN Recomposition

This textbook trains English sentence movement, Chinese recomposition, and writing formation through Proustian materials.

It is not a final-translation display.

Each chapter follows:

Core Explanation -> Input -> Recognition Drill -> Recomposition Drill -> AI Feedback -> Repair Drill -> Thinking Question -> Transfer Drill -> Teacher Note -> Movement Card.

AI may coach and correct after the learner attempts the passage. It must not provide final translation before the learner's attempt.
