# Reading Actions

Reading Actions are the basic units of training.

They keep the system from drifting into appreciation, summary, theory, or coverage.

## Core Actions

## Mark Sentence Movement

Identify where the sentence delays, qualifies, inserts, suspends, turns, or releases force.

Output:

- movement marks
- one sentence about how the movement affects perception

## Identify Delay Structures

Find what the passage withholds and when recognition becomes possible.

Output:

- delayed element
- trigger of recognition
- effect on the reader's perception

## Compare Rhythms

Compare how thought moves as rhythm before it becomes concept.

Output:

- Proust rhythm note
- comparative rhythm note
- difference statement

## Trace Temporal Logic

Name how time operates in the passage.

Output:

- temporal pattern
- sequence pressure
- return-to-Proust observation

## Detect Abstraction Pressure

Observe when the passage becomes conceptual.

Output:

- early, delayed, withheld, historical, or emergent abstraction
- evidence from sentence behavior

## Identify Perceptual Regimes

Name the kind of perception the passage trains.

Output:

- perception regime label
- one concrete mark from the passage
- contrast with Recherche

## Infer Structural Difference

State the mechanism revealed by comparison.

Output:

- not a theme
- not a summary
- one structural difference that changes how Recherche is read

## Restate Literary Mechanism

Restate what the passage does in the reader's own words.

Output:

- one precise paragraph
- no decorative appreciation
- return to the Proust passage

## Multilingual Recomposition

Ask what survives, mutates, compresses, expands, or reorganizes across French, English, and Chinese.

Output:

- transfer observation
- recomposition problem
- return-to-Proust note

## Minimum Lesson Action Set

Every future lesson must include:

1. one movement mark
2. one rhythm comparison
3. one temporal logic trace
4. one structural restatement
5. one return-to-Proust observation
