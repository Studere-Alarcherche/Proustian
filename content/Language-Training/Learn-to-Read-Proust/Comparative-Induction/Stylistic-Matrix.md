# Stylistic Matrix

The Stylistic Matrix converts passage comparison into repeated reading actions.

It is not a taxonomy for classification. It is a pressure surface for induction.

## Matrix Fields

Each passage pair or passage cluster should be read through these fields:

| Field | Proust Question | Comparative Question | Induction Product |
| --- | --- | --- | --- |
| Sentence movement | How does the sentence delay, expand, qualify, or redirect? | How does the comparative passage move differently? | Named movement pattern |
| Temporal logic | How does the passage make time readable? | Is time flowing, ruptured, reflected, compressed, or rearranged? | Temporal contrast note |
| Perceptual regime | What does the passage train the reader to notice? | What kind of perception becomes dominant by contrast? | Perception regime label |
| Rhythm | Where does rhythm carry thought before concept? | Is rhythm wave-like, broken, measured, compressed, or impersonal? | Rhythm description |
| Abstraction pressure | When does the passage become conceptual? | Is abstraction early, delayed, withheld, or historical? | Abstraction timing note |
| Multilingual transfer | What pressure belongs to French, English, or Chinese? | What survives, mutates, compresses, or expands? | Transfer observation |
| Return to Recherche | What becomes sharper in Proust? | What did the difference amplify? | Return statement |

## Matrix Use

Use the matrix slowly.

Do not fill it as a checklist. Let repeated fields produce pattern recognition over time.

Each completed matrix should produce:

- one movement pattern
- one temporal contrast
- one perception label
- one return-to-Proust statement

## Prohibited Use

Do not use the matrix to rank authors.

Do not use it to decide which passage is better.

Do not use it to create summaries, themes, or encyclopedia entries.

The matrix exists to train perception through difference.
