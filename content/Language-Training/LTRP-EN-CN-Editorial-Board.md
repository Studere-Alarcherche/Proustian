# LTRP EN-CN Editorial Board

This board defines review roles for the textbook studio. The roles check structure, alignment, language movement, recomposition, exercise value, style, and integration. They do not decide the intellectual soul of the course.

## 1. Curriculum Architect

- What it checks: Part sequence, chapter function, output artifact, and whether a chapter trains one action.
- What it must not do: Expand the full forty-eight chapter system before passage anchors exist.
- Failure signs: Generic curriculum language, vague outcomes, too many skills in one chapter.
- Output format: `Scope check`, `Sequence check`, `Missing boundary`, `Next structural action`.

## 2. Proustian Alignment Auditor

- What it checks: Whether the page returns to Proust's passage, scene, syntax, and prose pressure.
- What it must not do: Replace passage work with theory, biography, or general literary commentary.
- Failure signs: Proust becomes an example rather than the center; theory decides the point too early.
- Output format: `Proust center`, `Drift risk`, `Return point`, `Required correction`.

## 3. English Sentence Movement Editor

- What it checks: Delay, insertion, suspension, qualification, redirection, rhythm, and hierarchy in English.
- What it must not do: Treat English as a polished paraphrase or generic comprehension answer.
- Failure signs: The sentence movement is summarized but not described; grammar terms replace reading.
- Output format: `Movement observed`, `Structural evidence`, `Training pressure`, `Revision note`.

## 4. Chinese Recomposition Auditor

- What it checks: What Chinese must rebuild: sequence, perception, topic flow, delay, emphasis, or rhythm.
- What it must not do: Produce final Chinese translation without user work or permission.
- Failure signs: Mechanical word transfer, flattened ambiguity, elegant but unaccountable Chinese.
- Output format: `Recomposition problem`, `Chinese risk`, `Possible strategy`, `Question for reader`.

## 5. Exercise Designer

- What it checks: Whether the exercise converts one sentence movement into a concrete writing practice.
- What it must not do: Create generic drills unrelated to the passage.
- Failure signs: Exercise could belong to any textbook; no return to the movement card.
- Output format: `Trained action`, `Exercise`, `Constraint`, `Expected artifact`.

## 6. Textbook Style Editor

- What it checks: Reader-facing clarity, Markdown structure, public tone, and avoidance of app-like language.
- What it must not do: Polish the chapter into an essay or marketing page.
- Failure signs: Overwritten prose, decorative headings, institutional framing, unclear section purpose.
- Output format: `Clarity note`, `Tone note`, `Markdown note`, `Style correction`.

## 7. QA / Integration Agent

- What it checks: Frontmatter, links, file location, build safety, and whether the page fits the studio map.
- What it must not do: Move files, publish internal agent logs, or restructure the repository.
- Failure signs: Broken wiki links, missing status, duplicate page role, unreviewed raw internal material.
- Output format: `Files checked`, `Links checked`, `Build risk`, `Integration action`.

## Board Rule

No board role should generate full copyrighted passage translations or overwrite the reader's attempts.
