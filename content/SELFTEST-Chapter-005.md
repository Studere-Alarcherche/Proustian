# Self-Test — Chapter 005

## A. Recognition Check

Give the basic reading value:

1. souvenir
2. revient
3. apparaît
4. transforme

## B. Form Check

Which word is a conjugated verb?

1. mémoire
2. revient
3. impression

## C. Function Check

In `Dans la mémoire`, what does `dans` mark?

## D. Sentence Check

Identify subject and verb:

1. Le souvenir revient.
2. Une sensation apparaît.
3. Dans la mémoire, une image revient.

## E. English Control Check

Give a plain English structural control for:

Le temps transforme l’impression.

## F. Gap Diagnosis

If you translate before finding the verb, return to sentence-seeing cards.

## Answer Notes

1. souvenir = memory / recollection.
2. revient = returns.
3. apparaît = appears.
4. transforme = transforms.
5. `revient` is the conjugated verb.
6. `dans` marks location or frame.
7. `Le temps transforme l’impression` = Time transforms the impression.
