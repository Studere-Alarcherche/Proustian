# SKILL-Cognate-Mapping

## Purpose

Use French-English cognates as the first acceleration layer for reading French.

This skill builds early reading confidence without pretending that visual recognition equals mastery.

## When to Use

- Chapter 001
- vocabulary banks
- recognition cards
- early reading confidence exercises
- first-pass review of Proust-oriented vocabulary

## Inputs

- French word list
- expected English recognition
- similarity pattern
- Proustian lexical field, if any
- target card type

## Procedure

1. Identify visually recognizable French words.
2. Map to English equivalents.
3. Mark similarity pattern.
4. Warn that recognition is not mastery.
5. Convert into recognition cards.
6. Connect to Proustian lexical fields when possible.

Examples:

- mémoire → memory
- sensation → sensation
- impression → impression
- attention → attention
- perception → perception
- image → image
- forme → form
- possible → possible
- visible → visible
- nature → nature
- silence → silence
- moment → moment

## Output Format

## Cognate Mapping

| French | English Recognition | Pattern | Proustian Use | Card Target |
|---|---|---|---|---|

## Audit Questions

- Is the word visually recognizable to an English reader?
- Is the English recognition close enough for first-pass reading?
- Is any semantic drift marked?
- Does the mapping support reading rather than vocabulary display?
- Can the word become a short recognition card?
- Does the word belong to a useful Proustian lexical field?

## Failure Signals

- treats cognates as fully mastered words
- ignores semantic drift
- uses random vocabulary unrelated to reading
- no card conversion
- no Proustian direction
- encourages uncontrolled guessing
