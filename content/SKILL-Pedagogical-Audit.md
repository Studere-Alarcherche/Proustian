# SKILL-Pedagogical-Audit

## Purpose

Audit whether a textbook page, chapter, card set, or self-test has pedagogical reliability.

This skill prevents the Language Training system from accepting material because it sounds elegant. A page is accepted only when it trains a visible reading action, can be converted into cards, can be self-tested, and can be revised from failure.

## When to Use

- before accepting a chapter
- before marking a chapter stable
- before expanding the sequence
- when an agent suspects beautiful but weak material
- after a self-test exposes unclear learning value

## Inputs

- target page, chapter, card set, or self-test
- intended chapter level
- relevant source tradition
- intended card targets
- diagnostic categories likely to apply

## Procedure

Check:

1. What does this material train?
2. Why is this sequence justified?
3. Which reading-textbook tradition supports it?
4. Which SLA / input-processing principle supports it?
5. What observable behavior proves learning?
6. What learner failure would force revision?
7. What cards preserve the knowledge?
8. What diagnostic category repairs failure?

## Output Format

## Pedagogical Audit

### Learning Target

### Source Tradition

### Observable Evidence

### Falsification Trigger

### Card Conversion

### Diagnostic Categories

### Verdict

Pass / Revise / Reject

## Audit Questions

- Is the learning target observable?
- Does the sequence follow a defensible reading-language tradition?
- Does the explanation train a reading action rather than only name a concept?
- Can the material generate reviewable cards?
- Can a self-test expose a failure?
- Can the Diagnostic Tutor classify the failure?
- Does the material serve Proustian reading pressure without forcing Proust too early?

## Failure Signals

- no observable learning behavior
- no card-conversion potential
- vague "understanding" language
- cannot be self-tested
- not connected to Proustian reading
- source tradition is decorative rather than functional
- failure would not change the chapter

## Related Agents

- Textbook Architect
- Final Examiner
- Diagnostic Tutor
- Builder / Integrator
