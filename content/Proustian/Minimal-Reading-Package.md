# Minimal Reading Package V0.1

## Purpose

This page gathers the first usable reading entrances for Proustian 2.0. It does not replace reading. It gives the reader a small number of passages, questions, and directions from which reading can begin.

## How to use this page

1. Choose one entrance.
2. Locate the passage.
3. read the passage.
4. write one question.
5. turn the question into a Passage Card.
