# Pedagogical Audit Principles

## Purpose

Every page of Learn to Read French / Learn to Read Proust must be auditable.

A chapter is not accepted because it sounds elegant.

It is accepted only if it has a clear learning target, a reliable pedagogical source, a visible reading action, card-conversion potential, and self-testing value.

## Source Traditions

The textbook draws from five traditions:

1. Reading-knowledge French textbooks
2. Classical-language reading textbooks
3. Instructed second language acquisition
4. Input processing and form-meaning mapping
5. Retrieval practice through cards and diagnostic feedback

## Reading-Knowledge French Textbook Tradition

Examples:

- _French for Reading_
- _A Short Course in Reading French_
- French for Reading Knowledge courses

Principles:

- begin with cognates and recognition
- introduce false friends early
- teach word families
- prioritize function words
- teach reading grammar, not conversation-first French

## Classical-Language Reading Textbook Tradition

Examples:

- _Learn to Read Latin_
- _Learn to Read Greek_

Principles:

- morphology and syntax must be explicit
- literary target text motivates the sequence
- early forms and grammar prepare for later difficult texts
- reading goal is central

## Instructed SLA

Principles:

- instruction must have clear learning targets
- learner performance must be observable
- no single theory is sufficient
- chapters must be revised from evidence

## Input Processing

Principles:

- teach form-meaning mapping
- every structure should trigger a reading action
- grammar is not only rule explanation, but processing training

## Vocabulary Acquisition Through Reading and Repetition

Principles:

- vocabulary grows through recognition, recurrence, word families, and review
- Anki cards convert knowledge into retrievable memory
- false friends and function words require repeated exposure

## Self-Tested Design

Principles:

- the editor is the first learner
- no chapter becomes stable before self-testing
- failed cards and failed self-tests revise the chapter
- public method comes after self-verification

## Reliability Standard

Every chapter must answer:

1. What reading ability does this chapter train?
2. Which mature textbook tradition supports this sequence?
3. Which SLA principle supports this training action?
4. What observable learner behavior will show success?
5. What failure would falsify or weaken this chapter?
6. What cards should be created?
7. What self-test checks the chapter?
8. How will the Diagnostic Tutor classify failure?

## Scientific Temper

The system must remain falsifiable.

If a chapter does not improve recognition, parsing, or reading confidence, it must be revised.

If a card is too vague to review, it must be split or deleted.

If a self-test does not expose a gap, it must be rewritten.

If a Proust-oriented example is too difficult for the stage, it must be simplified.

## Core Rule

No chapter becomes stable until it has been self-tested by the editor.
