# README for Obsidian

This repository is used as a local reading and course-building system.

Use Obsidian for:

- reading notes
- course page drafting
- question extraction
- current-state preservation
- training notes
- internal navigation

Use Quartz for:

- public-facing course pages
- reading garden publication
- clean navigation
- external presentation

Local opening routine:

1. Open [[START-HERE]]
2. Check [[NEXT-ACTION]]
3. Check [[CURRENT-STATE]]
4. Work on one page or one reading task only
5. Update Current State only when the project direction actually changes

Do not use Obsidian to endlessly reorganize the system.
The repository exists to support reading, training, judgment, and course production.
