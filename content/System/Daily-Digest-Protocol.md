# Daily Digest Protocol

Daily is the RAW Capture Surface.

AI is the Digest Layer.

The Daily note itself does not need fields, sections, goals, tasks, wins, reflections, KPIs, completion metrics, or training checklists. It can contain fragments, reactions, questions, references, observations, paragraphs, unfinished claims, links, and random associations.

## Workflow

Raw Daily Log -> AI Digest -> Optional Fixation

Human work:

- reading
- thinking
- writing
- judgment
- direction

AI work:

- extraction
- compression
- clustering
- routing
- archive judgment

## Digest Categories

### Heated Questions

Questions repeatedly appearing or generating pressure.

### Project Decisions

Stable decisions affecting project structure.

### Language Training

French / English reading observations.

### Possible Essays

Ideas worth expanding.

### Proustian Updates

Material that should enter:

- Proustian
- Language Training
- Essays
- System

### Ignore

Noise, temporary thoughts, abandoned directions, or material that can remain only in Daily.

## Digest Prompt

```text
Organize this Daily Log.

1. Extract heated questions.
2. Extract project decisions.
3. Extract language-training observations.
4. Extract possible essays.
5. Extract content that should enter Proustian.
6. Mark content that can remain only in Daily.

Do not rewrite my voice.
Do not over-summarize.
Preserve original judgments.
Compress only where necessary.
```

## Boundaries

- Do not rewrite Raw.
- Do not sanitize tone.
- Do not force Daily into a template.
- Do not convert Daily into a dashboard, KPI system, review system, or productivity layer.
- Do not publish Raw by default.
- Classify after heat.
