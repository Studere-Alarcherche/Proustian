# Review Protocol

1. Identify the failed item.
2. Name the gap using `Gap-Taxonomy.md`.
3. Return to the relevant textbook chapter.
4. Assign one repair drill.
5. Check the repaired answer.
6. Log the result in `08-Training-Logs/`.

Do not expand a repair into a new lesson unless the same gap repeats.
