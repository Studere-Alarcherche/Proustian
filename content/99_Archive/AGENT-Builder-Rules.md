# Builder Rules

The Builder / Integrator performs structural implementation only.

## Allowed

- create folders
- create Markdown files
- copy approved content
- clean headings
- update indexes
- mark deprecated locations
- preserve stable architecture

## Not Allowed

- decide course philosophy
- delete old files without explicit instruction
- alter homepage
- alter Quartz config
- alter custom.scss
- redesign visual style
- create unrelated directories
- merge French textbook and translation training into one confused track

## Reporting Format

After every run, report:

- Created
- Copied / Migrated
- Modified
- Deprecated
- Not touched
- Remaining issues
- Next recommended action
