# Repository Maintenance

This note records the current maintenance stance for Proustian.

## Repository Role

Proustian is the Obsidian reading repository and Quartz public course garden for Proustian 2.0.

The active workflow is:

Local Source Repository -> NotebookLM U1-U6 -> Obsidian Reading Repository -> GitHub / Quartz Public Course Garden -> WeChat Public Writing

## Boundaries

- Proust remains the center.
- Deleuze is a method lens, not a top-level replacement.
- French supports language precision, not a separate public course unit.
- Obsidian remains the private working layer.
- Quartz remains the public reader-facing garden.
- Codex performs structural maintenance, not thesis invention.

## Cleanup Policy

Safe deletion:
- generated macOS files
- cache folders
- build output
- obsolete plugin binaries
- dead deployment or preview automation
- upload state files

Archive instead of delete:
- old course drafts
- old conversation distillations
- noncanonical project notes
- source-locator notes
- old public-writing drafts

Keep and normalize:
- flat Markdown entry files
- active reading maps
- passage cards
- question gradients
- build logs
- Quartz configuration
- vault-local Obsidian settings under `content/.obsidian/`
