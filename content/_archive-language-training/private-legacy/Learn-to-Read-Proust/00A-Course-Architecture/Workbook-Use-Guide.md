# Workbook Use Guide

The workbook is for active structural practice.

Use each workbook chapter after reading the corresponding textbook chapter.

Standard drill sequence:

- Drill A: see the sentence.
- Drill B: identify subject and verb.
- Drill C: track word order.
- Drill D: give literal English control.
- Drill E: give natural English paraphrase.
- Drill F: run a structural check.
- Drill G: apply the skill to a Proust-oriented sentence.
- Drill H: complete cumulative review.

The workbook should not include Chinese paraphrase exercises. English is the scaffold language for learner-facing work.

The answer key must mirror every workbook drill.
