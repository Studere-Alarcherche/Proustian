# Reading Progression

The reading progression moves from structure to Proust.

Stage 1: See the sentence.

- full sentence
- subject group
- conjugated verb
- completion or no completion

Stage 2: See forms.

- nouns
- gender
- number
- articles
- present-tense verb forms

Stage 3: See relations.

- adjectives
- prepositions
- negation
- objects and complements

Stage 4: See memory and time.

- past tenses
- participles
- infinitives
- narrative sequence

Stage 5: See delay.

- relative clauses
- que-clauses
- subordinate material
- delayed main verbs

Stage 6: See Proustian periods.

- apposition
- parenthesis
- accumulated modifiers
- sentence suspension
- paragraph reading
