# Workflow

1. Select the chapter from `Chapter-Sequence.md`.
2. Draft the textbook chapter.
3. Draft the workbook chapter from the same grammar and vocabulary.
4. Draft the answer key after the workbook is stable.
5. Add or update paradigms when a new form set appears.
6. Record source-corpus notes when examples are adapted from Proust.
7. Run an agent review.
8. Revise for sequence, answerability, and Proust orientation.

Each chapter packet should remain aligned:

- textbook chapter number
- workbook chapter number
- answer-key chapter number
- review file number

Do not expand the structure into a folder-heavy system unless explicitly requested.
