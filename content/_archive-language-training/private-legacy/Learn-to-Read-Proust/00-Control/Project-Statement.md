# Project Statement

Learn to Read Proust is a private self-study French reading course.

Its final and only target text is Marcel Proust, _A la recherche du temps perdu_.

The project is organized as a rigorous textbook + workbook + answer-key system. It is not a general French course, not a conversation course, and not a survey of French literature.

Every chapter should train one reading skill that later becomes necessary for reading Proust with control: sentence recognition, forms, vocabulary, parsing, syntax, memory structures, subordination, and long-period reading.

The course should remain cumulative. New grammar should be introduced in sequence, practiced in drills, checked in the answer key, and reviewed later.
