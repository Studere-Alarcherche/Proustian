# Daily

Daily is the RAW Capture Surface.

Write first. Classify later.

A Daily note may contain fragments, reading reactions, questions, passage references, language observations, project thoughts, free paragraphs, unfinished claims, links, and random associations.

No fields are required. No mandatory sections are required. Daily is not a task sheet, template journal, KPI surface, or productivity layer.

Use [[../System/Daily-Digest-Protocol|Daily Digest Protocol]] after writing when a log needs AI digestion.
