# SKILL-Function-Word-Control

## Purpose

Train the reader to treat small French words as structural controls.

This skill makes function words central to reading rather than decorative or merely translational.

## When to Use

- Chapter 004
- function word banks
- sentence parsing
- Proust long-sentence preparation
- diagnostic repair after attachment errors

## Inputs

- function word
- sentence or phrase context
- structural function
- reading action
- target card type

## Procedure

1. Identify the function word.
2. Ask what relation it creates.
3. Do not translate too quickly.
4. Mark attachment.
5. Convert into function-recognition cards.

Core function words:

- de
- à
- et
- mais
- dans
- sur
- avec
- sans
- comme
- que
- qui
- dont
- où
- en
- y
- chez

Function categories:

- relation / possession
- direction / target
- location
- contrast
- addition
- comparison
- clause boundary
- reference
- domain / intellectual location

## Output Format

## Function Word Control

| Word | Structural Function | Reading Action | Example | Card Target |
|---|---|---|---|---|

## Audit Questions

- Does the explanation identify a structural function?
- Does it train a reading action?
- Does it show attachment or relation?
- Does it avoid giving only a dictionary translation?
- Can the item become a function-recognition card?
- Does the item prepare for Proustian long sentences?

## Failure Signals

- treats function word as decorative
- gives only dictionary translation
- does not show reading action
- no sentence attachment
- no card conversion
- function word is introduced without future parsing value
