# Quartz Page Publisher

Use this skill when creating, auditing, or preparing a public-facing Quartz Markdown page.

## Purpose

Quartz is the public reading garden. It should stay Markdown-first, reader-facing, and structurally light.

## Workflow

1. Confirm the target file and publication role.
2. Preserve `content/index.md` as the homepage.
3. Use flat public-facing files unless the existing structure requires otherwise.
4. Preserve Obsidian wiki links.
5. Avoid student, teacher, classroom, and instructor language in public pages.
6. Keep public pages in English unless explicitly approved.
7. Run link and build checks only when requested or appropriate.

## Output Shape

- Purpose
- Reader path
- Links
- Open questions
- Next reading action

## Rules

- Do not create `Index.md`, `INDEX.md`, or repo-root `index.md`.
- Do not introduce large HTML blocks.
- Do not use inline CSS.
- Do not restructure `content/`.
- Do not rewrite public pages unless explicitly asked.
