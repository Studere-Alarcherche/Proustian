# Design Audit Reading Site

Use this skill when reviewing or planning Proustian visual design for Quartz or the future web app.

## Design Direction

Preferred mood:

- dark archive
- observatory
- reading chamber
- manuscript texture
- memory palace
- textual apparatus

Avoid:

- SaaS style
- generic card grid
- bright cheap yellow
- marketing CTA
- LMS aesthetics
- crowded dashboards

## Workflow

1. Identify the surface: Quartz page, app shell, text chamber, or plate map.
2. Check whether Proust remains visually central.
3. Check density, hierarchy, and reading comfort.
4. Check whether UI components serve close reading rather than product marketing.
5. Flag any generic dashboard or LMS drift.

## Output Shape

- Surface audited
- What works
- Risks
- Required changes
- What not to change

## Rules

- Do not redesign Quartz unless asked.
- Do not implement a web app unless approved.
- Do not add decorative complexity that weakens reading.
- Do not use marketing language for reader-facing tools.
