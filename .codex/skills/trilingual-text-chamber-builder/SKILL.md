# Trilingual Text Chamber Builder

Use this skill when preparing a French / English / Chinese reading chamber for a Proust passage.

## Purpose

The chamber supports precise reading across languages. It is not a classroom worksheet and not a full translation project.

## Inputs

- French source text when available
- English translation or reading translation
- Chinese notes or translation draft
- target passage boundary
- unresolved vocabulary or syntax pressure

## Workflow

1. Separate source, translation, and commentary.
2. Preserve the French as the authority when available.
3. Use English for reader-facing orientation.
4. Use Chinese for private precision, memory, and drafting when useful.
5. Mark uncertain translation choices explicitly.
6. Extract only the vocabulary or syntax needed for the passage.

## Output Shape

- Passage boundary
- French text
- English rendering
- Chinese rendering / notes
- Syntax pressure
- Vocabulary pressure
- Translation risk
- Reading question

## Rules

- Do not invent source text.
- Do not flatten ambiguity.
- Do not turn the chamber into a language course page unless asked.
- Do not modify public files without explicit permission.
