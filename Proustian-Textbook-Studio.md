# Learn to Read Proust [EN-CN] Textbook Studio

## Project Identity

Learn to Read Proust [EN-CN] is the current textbook studio for using *In Search of Lost Time* to train English reading, Chinese recomposition, and prose formation.

This studio absorbs the earlier Translation-Lab direction. Translation-Lab is no longer a separate project name. Translation remains a method inside Learn to Read Proust [EN-CN], not the controlling identity.

## Current Phase

The current phase is EN-CN only.

Work in this phase should use English passages and Chinese recomposition practice. Do not begin FR-EN-CN translation collation yet.

## Future Phase

When French familiarity is sufficient, the studio may expand into FR-EN-CN translation collation.

That later phase should compare French source movement, English translation pressure, and Chinese recomposition. It should not be started inside the current EN-CN control cycle.

## Book Structure

The core structure is:

- 8 Parts
- 6 Chapters per Part
- 48 Chapters total

Each chapter trains one reading move. Each 6-chapter Part completes one production cycle and feeds reusable observations back into skills, pattern notes, and error warnings.

## 6-Chapter Part Cycle

Each Part follows this default rhythm:

1. Introduce the move
2. Variant or complication
3. Translation pressure
4. Chinese recomposition
5. Writing transfer
6. Review, consolidation, and extension

This rhythm is a default operating structure, not a rigid folder system.

## Studio Workflow

Corpus -> Passage Selection -> Chapter Draft -> Pattern Extraction -> Exercise Design -> Error Detection -> Skill Update -> Next Chapter -> 6-Chapter Part Consolidation -> Next Part -> Book Revision

In Chinese:

文本底本 -> 选段 -> 章节 -> 模式提取 -> 练习设计 -> 错误发现 -> 技能更新 -> 下一章 -> 六章 Part 收束 -> 下一 Part -> 全书修订

## Operating Rule

Build the textbook by small repeatable cycles:

- select real passages
- map passages to a chapter function
- draft one chapter at a time
- extract patterns from actual work
- record errors after use
- update skills only when the need is observed

Do not create fake Proust passages. Do not write the full book before the Part I prototype is tested.

## First Prototype

The first production target is:

Part I: How a Long Sentence Delays Thought

Prototype scope:

- select 8-12 candidate passages from available *In Search of Lost Time* text
- map them to the six Part I chapters
- fully draft Chapter 1 only
- generate Chapter 1 exercises
- extract Chapter 1 patterns
- update the Skill-Error-Update Log
- decide whether Chapter 2 should follow the same template
